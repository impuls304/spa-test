# ИИ-помощник по складскому учёту

Демонстрационный MVP для нормализации складских записей, прогнозирования
потребности и формирования плана закупок по вопросам на русском языке.

## Возможности

1. `normalize_movement` извлекает дату, SKU, объект, операцию, количество,
   единицу, партию и документ из неструктурированного текста.
2. `forecast_demand` рассчитывает спрос, страховой запас, точку заказа,
   рекомендуемое количество, стоимость, дату исчерпания и `confidence`.
3. `answer_question` распознаёт складской запрос, проверяет обязательные
   параметры и формирует объяснимый ответ на основе расчётного модуля.

GigaChat используется для семантического разбора свободных формулировок.
Все количества и суммы рассчитываются детерминированно в Python. Без API-ключа
автоматически работает локальный fallback.

## Структура

- `normalization.py` — нормализация движений товара;
- `forecasting.py` — прогноз и рекомендация закупки;
- `question_parser.py` — локальный разбор вопросов;
- `gigachat_parser.py` — OAuth и семантический разбор через GigaChat;
- `questions.py` — проверка параметров и формирование ответа;
- `acceptance.py` — контрольные вопросы и сквозной сценарий;
- `dataset.json`, `catalog.json`, `locations.json` — синтетические данные;
- `acceptance_questions.json` — 25 контрольных сценариев;
- `RESULTS.md` — результаты и обоснование решений.

## Установка

Требуется Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

На Windows виртуальное окружение активируется командой:

```powershell
.venv\Scripts\activate
```

## Запуск

Полный демонстрационный пайплайн без внешнего API:

```bash
python -m inventory_ai demo --offline
```

Один вопрос:

```bash
python -m inventory_ai ask "Посчитай закупку SCRB-020 на 30 дней"
```

Дополнительные режимы:

```bash
python -m inventory_ai ask "Какой бюджет закупок на квартал?" --details
python -m inventory_ai ask "Что нужно заказать на 30 дней?" --json
python -m inventory_ai ask "Посчитай закупку SCRB-020 на 30 дней" --offline
```

Тесты:

```bash
python -m pytest -q
```

## GigaChat

CLI загружает настройки из локального `.env` или переменных окружения:

```text
GIGACHAT_AUTH_KEY=<Authorization key>
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2-Max
GIGACHAT_CA_BUNDLE=<путь к PEM, если требуется>
```

Authorization key уже является Base64-представлением пары
`Client ID:Client Secret`; повторное кодирование не требуется. `.env` исключён
из Git. Access token хранится только в памяти.

Модель получает вопрос, дату данных и названия товаров. Остатки, цены и история
расхода ей не передаются. Предложенные SKU и параметры проверяются локально.
При ошибке API используется локальный разбор.

## Ограничения MVP

- неоднозначный товар и отсутствующий период требуют уточнения;
- расчёты по филиалу не выполняются без истории и остатков этого филиала;
- сроки годности требуют данных о партиях, динамика цен — истории цен;
- дата исчерпания не учитывает поставку в пути без известной даты прибытия;
- автоматическое размещение заказа не выполняется.

Подробные результаты всех трёх частей приведены в `RESULTS.md`.
